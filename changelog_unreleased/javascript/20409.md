#### Keep punctuation separator text runs whole when wrapping JSX (#20409 by @prettier-bot)

When a JSX text run that is only a punctuation word between single spaces (such as `·`) sits between two non-text children and the line has to break, it is now printed as one string expression instead of being split into raw text plus a standalone `{" "}`. The surrounding text runs are left intact.

<!-- prettier-ignore -->
```jsx
// Input
<div style={{ letterSpacing: ".15px" }}>→ Next: <strong>{label}</strong> · {date}</div>

// Prettier stable (--print-width 40)
<div style={{ letterSpacing: ".15px" }}>
  → Next: <strong>{label}</strong> ·{" "}
  {date}
</div>;

// Prettier main (--print-width 40)
<div style={{ letterSpacing: ".15px" }}>
  → Next: <strong>{label}</strong>{" · "}
  {date}
</div>;
```
