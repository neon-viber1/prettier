#### Format comments before an empty loop or `if` body consistently (#9999 by @contributor)

<!-- prettier-ignore -->
```jsx
// Input
while (true) /* Comment */
{}

if (true) // Comment
{}

// Prettier stable
while (true) /* Comment */ {}

if (true) // Comment
{
}

// Prettier main
while (true) {
  /* Comment */
}

if (true) {
  // Comment
}
```
