#### Fix inconsistent output for a comment after an optional chain followed by a non-null assertion (#18667 by @prettier-contributor)

When a line comment follows a parenthesized optional chain that is followed by `!`, the `babel-ts` parser used to break the member chain after the assertion, while the other TypeScript parsers did not. The line comment is printed after the statement, because code cannot follow a line break between the parenthesized chain and `!`. All TypeScript parsers now print the same output.

<!-- prettier-ignore -->
```ts
// Input
(a?.b
  //comment
)!.bar();

// Prettier stable (babel-ts)
(a?.b)!
//comment
  .bar();

// Prettier main (all TypeScript parsers)
(a?.b)!.bar();
//comment
```
