#### Preserve import attributes in TypeScript ambient module declarations (#20531 by @fisker)

When a parser produces `attributes` for a `TSModuleDeclaration`, they are now printed instead of being silently dropped, which previously changed which imports the declaration matched.

<!-- prettier-ignore -->
```ts
// Input
declare module "*" with { type: "text" } {
  const content: string;
  export default content;
}

// Prettier stable
declare module "*" {
  const content: string;
  export default content;
}

// Prettier main
declare module "*" with { type: "text" } {
  const content: string;
  export default content;
}
```
