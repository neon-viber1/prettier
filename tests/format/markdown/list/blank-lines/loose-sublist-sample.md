# Recording

1. Go to **File / Settings**
2. In the **Audio** tab and configure devices as follows

   - **Desktop Audio**: Disabled
   - **Mic/Auxilary Audio**: ADAT

   ![OBS](a.png)

3. In the **Output** tab

   <img src="a.png" alt="x" width="45%">

4. Open **Edit**

   - **Mic/Aux**: Tick track 1 only
   - **Mic/Aux 2**: Tick track 2 only

   ![OBS](b.png)

5. Done
